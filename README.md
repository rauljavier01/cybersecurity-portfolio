## Project 1: Botium Toys - Internal Security Audit & Compliance Assessment

### Overview
Botium Toys is a growing U.S. toy retailer expanding its global presence. This internal audit assesses the company's security posture, risk management, and compliance status using the NIST Cybersecurity Framework (NIST CSF).

### Audit Scope & Objectives
* **Scope:** Entire security infrastructure, operational procedures, assets, and data management practices.
* **Goals:** Identify operational risks, evaluate control implementation, and ensure compliance with PCI DSS, GDPR, and SOC standards.

### Key Findings
* **Access Control:** Lack of least privilege and separation of duties; all employees currently have broad access to internal data and cardholder information.
* **Data Protection:** Absence of encryption for sensitive customer data and cardholder details.
* **Network & Systems:** Functional firewall and regularly monitored antivirus software are present, but an Intrusion Detection System (IDS) and automated data backups are missing.
* **Physical Security:** Adequate physical security including locks, CCTV, and functioning fire suppression systems.
